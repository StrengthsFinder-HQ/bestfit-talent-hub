# Roundtable feedback form (Google Forms)

1. Go to https://script.google.com, click **New project**, paste
   `create_feedback_form.gs`, save, and click **Run**. Approve the permissions
   Google asks for.
2. The execution log prints three links: the share link, the edit link and the
   responses sheet.
3. Open the edit link. Click the palette icon, choose **Upload header image**
   and pick `form_header.jpg`. Set the colour to `#F06424`.
4. In `../email.html`, the feedback button links to https://forms.gle/ywFcxYitEyFk56uT7.
5. Open the share link in a private window and submit a test answer. Then
   delete the test row from the responses sheet.

To get an email for each response: in the form, open **Responses**, click the
three dots, and turn on **Get email notifications for new responses**.
